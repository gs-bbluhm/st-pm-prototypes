The four states

OpenFired, nobody has responded. Counted, on the working list.
AcknowledgedSeen, being worked. Stays counted and on the list.
ResolvedHandled by a person. Leaves the working list, counts as a win.
DismissedSignal was right, nothing to do. Reviewable later.

Open is neutral gray, not a warning color. Resolved is the only green.

Empty and error states

  • Nothing open: "Nothing needs attention. 41 resolved this month." with a link to the resolved list.
  • Save fails: "Your note was not saved. Check your connection and try again." The text stays in the box.
  • No permission: button is disabled with the tooltip "Ask an admin for access to change status."

MVP

  • Status action and pop-up on Events report, Insights report, account Insights feed, email deep link
  • Four states, who and when, optional note that also lands in Notes
  • Status filter and column in both reports; counts split on dashboard cards
  • New firing starts Open; earlier decision kept in history
  • Reopen from any state

Soon after

  • Bulk action. Select rows in a report and acknowledge or resolve together. The weekly working list needs it.
  • @mention in the note to hand an item to a teammate (Notes @mention request).
  • Reason on dismiss from a short list (not relevant, already handled, expected) for later review.
  • Resolved report with win counts: risks closed, time to resolve, saved revenue.

Later, with AI

  • Suggested resolution. "The customer replied positively on 10/22. Mark resolved?" A person confirms. Human in the loop.
  • Auto-clear when the cause clears, for example the stakeholder gets contacted, shown as "Resolved automatically" and reopenable.
  • Aging nudge. "Acknowledged 7 days ago, no update" prompts the owner.
  • Notification quieting. Skip repeat alerts on acknowledged items; send a digest of unacknowledged ones.
  • Agents and Ask Staircase read status and notes so answers say what the team already decided.
  • MCP can set status with the same note.
